# gnustep-recommended-apps
A collection of GNUstep Recommended Applications to be used with AGNoStep Apps Manager.

## Goal

This module is useful with [agnostep-apps-manager](../../../agnostep-apps-manager).
It allows to retrieve the source of most of the known GNUstep Applications like GNUMail, SimpleAgenda...

> [!NOTE] This is a work in progress, as we are replacing previous `AgnostepManager.app` with this new module method.

## List of available applications

- AClock
- AddressManager
- AudioMixer
- Bean
- Cynthiune
- GNUMail
- Grr
- GSPdf
- HelpViewer
- InnerSpace
- Preview
- SimpleAgenda
- StepDown

> [!NOTE]
> Do NOT install AudioMixer on a RPI machine. You should use instead `AudioMixer` provided by [agnostep-applications](../../../agnostep-applications).
